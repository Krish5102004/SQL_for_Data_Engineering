## 🚀 Overview
This repository contains production-style SQL scripts, data transformations, and analytical queries designed for Data Engineering workloads. It demonstrates how raw, unstructured operational data is ingested, cleaned, modeled, and queried to drive business and technical insights.

## 🛠️ Tech Stack & Tools
* **Databases & OLAP Engines:** DuckDB, MotherDuck (Cloud OLAP), PostgreSQL
* **Development Environment:** VS Code, Git/GitHub, PowerShell
* **Core Competencies:** Data Modeling (Star Schema), ELT Transformations, Query Optimization, Analytical Reporting

## 🧠 Key SQL Engineering Concepts Demonstrated
* **Advanced Querying:** Modular Common Table Expressions (CTEs), Recursive Queries, and Correlated Subqueries.
* **Window Functions:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`, and rolling aggregations for time-series analysis.
* **Data Wrangling & Cleaning:** Handling `NULL` values, type casting, string parsing, deduplication, and date-time standardization.
* **Schema Design & DDL/DML:** Fact and Dimension table creation, constraints, indexing strategies, and partitioning concepts.
